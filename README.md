# מדריך רולטה — הגלגל וההימורים

מדריך ויזואלי בעברית להבנת לוח הרולטה, סדר המספרים בגלגל, וההימורים המוכרזים (Voisins, Tiers, Orphelins, שכנים).

## איך להשתמש
פתח את `index.html` בדפדפן.

## מה יש בקובץ
- **דיאגרמת גלגל** אינטראקטיבית עם כל 37 המספרים בסדר האמיתי שלהם על הגלגל האירופאי
- **צביעה לפי קבוצות**:
  - 🔵 כחול — Voisins du Zéro (17 מספרים סביב האפס)
  - 🟠 כתום — Tiers du Cylindre (12 מספרים מול האפס)
  - 🟣 סגול — Orphelins (8 "יתומים")
  - 🟢 ירוק — האפס
- **טבעת פנימית** מציגה את הצבע האמיתי (אדום/שחור) של כל מספר
- **לוח השולחן** עם 3 השורות של 12 מספרים, להבנת הימורי "שורה" (Street)
- **טבלת תשלומים** לכל סוגי ההימורים

## תזכורת חשובה
לכל ההימורים ברולטה אירופאית **אותו יתרון בית של 2.7%**.
שכנים, שורות, ומספרים בודדים — מתמטית שווי-ערך.
אין שיטה שמנצחת את הקזינו לאורך זמן.
