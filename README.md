# אפליקציית חיטוב חכמה 💪

אפליקציית עמוד-יחיד (קובץ אחד, ללא שרת) למעקב יומי אחר קלוריות, חלבון ומשקל — עם הצעות חכמות והתאמה אישית של היעדים.

## איך להשתמש
פתח את `index.html` בדפדפן. הכל נשמר מקומית בדפדפן (localStorage) — אין צורך בחיבור או הרשמה.

## מה יש באפליקציה
- **מעקב יומי** — לחיצה על מאכל מוסיפה קלוריות וחלבון לסיכום היום.
- **שמירה אוטומטית** — מה שאכלת היום נשמר גם אחרי רענון; יום חדש מתאפס אוטומטית לפי התאריך.
- **יומן אכילה** — רשימה של כל מה שהוספת, עם אפשרות למחוק כל פריט בנפרד.
- **הוספה ידנית** — הוספת מאכל חופשי עם קלוריות וחלבון משלך.
- **יעדים ניתנים לעריכה** — הגדר יעד קלוריות וחלבון משלך (ברירת מחדל: 2200 קק״ל / 160ג׳).
- **הצעות חכמות** — המלצות לפי הפער מהיעד (חסר חלבון, עודף קלוריות וכו׳).
- **מד התקדמות** — פסי התקדמות לקלוריות ולחלבון, שמסמנים באדום חריגה מהיעד.
- **גרף משקל** — מעקב משקל לאורך זמן (Chart.js), עם אפשרות למחוק רישום אחרון.

## הערות
- הנתונים נשמרים רק בדפדפן הנוכחי (localStorage) — ניקוי נתוני הדפדפן ימחק אותם.
- ערכי הקלוריות והחלבון של המאכלים הם הערכה כללית.
